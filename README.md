# Landing page · Dra. Alana Gabriela de Sales Maranhão

Landing page de página única para consultório odontológico em Campina Grande, PB. Conceito visual "Esmalte": porcelana, bordô, camadas translúcidas e brilho que segue o cursor.

**Página de demonstração.** CRO, formação, depoimentos, horários e equipamentos são ilustrativos e devem ser trocados por dados reais, em conformidade com o Código de Ética Odontológica (CFO).

## Estrutura

- `project/Main.dc.html`: a página, no formato de componente do editor Design (precisa do runtime dele para renderizar; não abre sozinha no navegador).
- `project/canvas.json`: índice do canvas.
- `assets/`: imagens usadas pela página (a página as referencia por `/_blob/<id>`).
